# Changes from the latest release

Latest release: 0.1.0 (beta).

- Chats open with their history already there. Instagram now brings each recent chat's messages, read in the
  background after the login and at every wake, back to 100 messages in the most recent chats, a page every few
  seconds. WhatsApp asks the person's phone for older messages of the most recent chats, a few requests a connection,
  until each has 100. Signal is unchanged: its linking transfer is all the history it offers.
